GodotDoctorCLIValidationReporter
================================

**Inherits:** :ref:`GodotDoctorValidationReporter<class_GodotDoctorValidationReporter>` **<** ``RefCounted``

Validation reporter for headless / CLI mode. Delegates rendering to :ref:`GodotDoctorReportPrinter<class_GodotDoctorReportPrinter>` using report objects built from validation collections. Exits the process with an appropriate code when validation is complete.
