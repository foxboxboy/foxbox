GodotDoctorNotifier
===================

**Inherits:** ``RefCounted``

A utility class for emitting debug prints and editor toast notifications. All methods are static; this class is not meant to be instantiated.

|void| **print_debug**\ (\ message\: ``String``, caller\: ``Variant`` = null\ ) |static| :ref:`🔗<class_GodotDoctorNotifier_method_print_debug>`

Prints ``message`` to the output console, prefixed with ``[GODOT_DOCTOR]`` (or ``[GODOT_DOCTOR->ClassName]`` when ``caller`` is provided), if :ref:`GodotDoctorSettings.show_debug_prints<class_GodotDoctorSettings_property_show_debug_prints>` is enabled in the plugin settings. ``caller`` can be an ``Object`` (its class name is used) or a plain ``String``.

.. _class_GodotDoctorNotifier_method_push_toast:

.. rst-class:: classref-method

|void| **push_toast**\ (\ message\: ``String``, severity\: ``int`` = 0\ ) |static| :ref:`🔗<class_GodotDoctorNotifier_method_push_toast>`

Pushes a toast notification to the editor toaster if toasts are enabled in settings. Only meaningful in editor mode; no-ops in CLI mode. ``severity`` controls the toast type: 0 for info (default), 1 for warning, 2 for error.

.. rst-class:: classref-method

``String`` **_resolve_prefix**\ (\ caller\: ``Variant``\ ) |static| :ref:`🔗<class_GodotDoctorNotifier_private_method__resolve_prefix>`

Resolves ``caller`` to a class-name string. If ``caller`` is a ``Script``, its ``class_name`` is returned when available. If ``caller`` is an ``Object``, its script ``class_name`` is preferred when available; otherwise its built-in class name is returned. If ``caller`` is a non-empty ``String``, it is returned as-is. Otherwise, an empty string is returned.
