GodotDoctorCLIValidationCollector
=================================

**Inherits:** :ref:`GodotDoctorValidationCollector<class_GodotDoctorValidationCollector>` **<** ``RefCounted``

A :ref:`GodotDoctorValidationCollector<class_GodotDoctorValidationCollector>` for CLI mode. Extends the base collector with support for :ref:`GodotDoctorValidationSuite<class_GodotDoctorValidationSuite>` grouping, aggregating scene and resource results per suite into a :ref:`GodotDoctorValidationSuiteValidationCollection<class_GodotDoctorValidationSuiteValidationCollection>`.
