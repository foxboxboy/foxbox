FoxHurtArea3D
=============

**Inherits:** ``Area3D``

Receives ``Variant`` payloads from physical interactions and routes them.

.. rst-class:: classref-introduction-group

Description
-----------

Acts as the receiving end of the Foxbox interaction pipeline. It listens for overlapping :ref:`FoxHitArea3D<class_FoxHitArea3D>` nodes and broadcasts their payload.
