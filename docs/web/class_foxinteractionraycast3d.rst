FoxInteractionRayCast3D
=======================

**Inherits:** :ref:`RayCast3D<class_RayCast3D>` **<** :ref:`Node3D<class_Node3D>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

A specialized raycast for detecting and managing focus on :ref:`FoxInteractableArea3D<class_FoxInteractableArea3D>` nodes.

.. rst-class:: classref-introduction-group

Description
-----------

**FoxInteractionRayCast3D** reports which :ref:`FoxInteractableArea3D<class_FoxInteractableArea3D>` it is pointing at and when that changes. 

\ **Note:** Ensure the raycast's Collision Mask is set only to your Interactables physics layer for optimal performance.
