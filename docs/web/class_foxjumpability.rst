FoxJumpAbility
==============

**Inherits:** :ref:`FoxNode<class_FoxNode>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

Component that manages the math, memory, and rules for jumping.

.. rst-class:: classref-introduction-group

Description
-----------

**FoxJumpAbility** tracks jump buffers, coyote time, and multi-jump charges without directly interacting with the character motor or physics body.
