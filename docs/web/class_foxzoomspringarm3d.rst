FoxZoomSpringArm3D
==================

**Inherits:** :ref:`SpringArm3D<class_SpringArm3D>` **<** :ref:`Node3D<class_Node3D>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

An extended :ref:`SpringArm3D<class_SpringArm3D>` designed for camera controllers.

.. rst-class:: classref-introduction-group

Description
-----------

It overrides standard length adjustments with smooth, frame-independent zoom interpolation and provides a dedicated API for stepping the zoom in and out.
