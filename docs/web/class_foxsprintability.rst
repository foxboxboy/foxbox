FoxSprintAbility
================

**Inherits:** :ref:`FoxNode<class_FoxNode>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

Component that manages the intents and threshold math for sprinting.

.. rst-class:: classref-introduction-group

Description
-----------

**FoxSprintAbility** tracks the player's sprint requests and provides the speed variables needed by the state machine, decoupling locomotion tuning from the root character.
