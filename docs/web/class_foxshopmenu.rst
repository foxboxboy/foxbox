.. _class_FoxShopMenu_signal_purchase_denied:

.. rst-class:: classref-signal

**purchase_denied**\ (\ item\: :ref:`FoxShopItem<class_FoxShopItem>`, reason\: :ref:`StringName<class_StringName>`\ ) :ref:`🔗<class_FoxShopMenu_signal_purchase_denied>`

Emitted when a purchase is attempted but fails. 

\ ``reason`` is ``&"no_wallet"`` when no wallet is assigned, or ``&"payment_refused"`` when the item's :ref:`FoxPrice<class_FoxPrice>` declined. The price decides why, and it does not have to be affordability, so do not present this to the player as "not enough money" without checking what your own :ref:`FoxPrice<class_FoxPrice>` meant by it.
