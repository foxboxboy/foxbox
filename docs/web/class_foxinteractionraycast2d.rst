.. rst-class:: classref-property-setget

- |void| **@interaction_range_setter**\ (\ value\: :ref:`float<class_float>`\ )

How far the raycast will project along the local +X axis. Leave as ``-1.0`` to ignore and use the manual :ref:`RayCast2D.target_position<class_RayCast2D_property_target_position>`. 

\ **Note:** 2D casts along +X, where the 3D one casts along -Z. That is the engine's convention for a node's forward direction in each dimension, not a difference in this class.
