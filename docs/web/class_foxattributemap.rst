FoxAttributeMap
===============

**Inherits:** :ref:`FoxNode<class_FoxNode>` **<** ``Node``

A recursive, hierarchical Blackboard node for safely managing dynamic entity data, stacked flags, and rules.

.. rst-class:: classref-introduction-group

Description
-----------

Acts as a centralized data hub for an entity. It can store any arbitrary ``Variant`` data (such as ``int``, ``String``, or :ref:`FoxStatPool<class_FoxStatPool>` resources), tracks temporary binary states via stacked string flags, and safely propagates :ref:`FoxAttributeRule<class_FoxAttributeRule>`\ s up and down a node hierarchy.
