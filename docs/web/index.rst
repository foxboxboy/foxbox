FoxFabric
=========

A lightweight, general purpose library for Godot 4.

Every page here is generated from the ``##`` documentation comments in the source, so this site
and the in-editor help always say the same thing. See ``docs/README.txt`` in the repo for how to
rebuild it.

Each module stands on its own. Copy the whole ``addons/foxfabric`` folder or pull out the single
directory you need.
