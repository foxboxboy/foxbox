FoxModifiableStat
=================

**Inherits:** :ref:`FoxResource<class_FoxResource>` **<** ``Resource``

A resource that calculates a final ``float`` value based on flat and multiplier modifiers.

.. rst-class:: classref-introduction-group

Description
-----------

Flat modifiers are added to :ref:`base_value<class_FoxModifiableStat_property_base_value>` first. The total is then multiplied by the sum of all multiplier modifiers.
