FoxShopCatalog
==============

**Inherits:** :ref:`FoxResource<class_FoxResource>` **<** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

An ordered list of :ref:`FoxShopItem<class_FoxShopItem>` resources offered by a shop.

.. rst-class:: classref-introduction-group

Description
-----------

**FoxShopCatalog** holds no transaction logic of its own. A catalog is only the stock list, so the same one can be shared between several shops or swapped out to change what a single shop sells.
