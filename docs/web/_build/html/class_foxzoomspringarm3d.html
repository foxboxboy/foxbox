FoxZoomSpringArm3D

Inherits: SpringArm3D

An extended SpringArm3D designed for camera controllers.

Description

It overrides standard length adjustments with smooth, frame-independent zoom interpolation and provides a dedicated API for stepping the zoom in and out.

Signals

length_changed(new_length: float) 🔗

Emitted when the arm’s zoom distance visually changes.

zoom_min_reached() 🔗

Emitted the moment the arm’s length reaches 0.0. Useful for hiding the player mesh.

zoom_max_reached() 🔗

Emitted the moment the arm reaches its max_length.

zoom_finished() 🔗

Emitted when the arm finishes interpolating and completely settles on the target_length.

Property Descriptions

float max_length = 200.0 🔗

The maximum distance the arm can zoom out.

float zoom_step = 1.0 🔗

The amount of length added or subtracted per zoom input.

float zoom_speed = 10.0 🔗

How quickly the camera interpolates to the target zoom. Higher values mean faster zooming.

bool zoom_enabled = true 🔗

Determines if the node currently accepts zoom inputs.

float target_length 🔗

The desired length the arm is currently interpolating towards.

Method Descriptions

void zoom_in() 🔗

Decreases the target length by the zoom_step, bringing the camera closer.

void zoom_out() 🔗

Increases the target length by the zoom_step, pushing the camera further away.

void change_zoom(amount: float) 🔗

Directly modifies the target length by a specific amount, clamping it to max_length.

float get_zoom_percentage() 🔗

Returns the current visual zoom as a decimal between 0.0 and 1.0.
