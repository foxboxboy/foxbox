FoxInteractionRayCast3D

Inherits: RayCast3D

A specialized raycast for detecting and managing focus on FoxInteractableArea3D nodes.

Description

Note: Ensure the raycast’s Collision Mask is set only to your Interactables physics layer for optimal performance.

Property Descriptions

float interaction_range = -1.0 🔗

  • void @interaction_range_setter(value: float)

How far the raycast will project along the local -Z axis. Leave as -1.0 to ignore and use the manual RayCast3D.target_position.
