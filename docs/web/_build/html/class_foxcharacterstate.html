FoxCharacterState

Inherits: FoxState < FoxNode < Node

Inherited By: FoxCharacterAirState, FoxCharacterDashState, FoxCharacterGroundedState

Base state for all character-driven states in the Foxbox framework.

Description

FoxCharacterState extends the generic FoxState by introducing strictly typed variables for core character components. These variables are automatically injected by the parent FoxCharacterStateMachine during initialization. Specific implementations should extend this class and use @export to define their own specific motor needs.

Properties

CharacterBody3D

physics_body

FoxCharacterModel

model

FoxCharacter

character

Property Descriptions

CharacterBody3D physics_body 🔗

The physics node of the character. Used by states and motors to apply velocity, detect floors, and handle world collisions.

FoxCharacterModel model 🔗

The visual and animation controller for the character. Used by states to command stances (e.g., crouch, stand) and trigger animations.

FoxCharacter character 🔗

Mediator for the entire character that exposes a huge API and inputs.
