FoxEffectInstance

Inherits: FoxRefCounted < RefCounted

A runtime state container for an active FoxEffect applied to a target Object.

Description

This class manages the active lifecycle of an effect, tracking its remaining time_left and current stack count. It is instantiated and managed exclusively by a FoxEffectManager.

Signals

stack_changed(previous_stack: int, new_stack: int) 🔗

Emitted when the stack count changes.

Note: This is ideal for connecting directly to UI elements to update visual counters (e.g., changing a poison icon from “x1” to “x2”) without polling.

request_destruction(instance: FoxEffectInstance) 🔗

Emitted when external logic forces this instance to expire prematurely. Triggers automatically when decrease_stack() causes the stack to reach 0.

Method Descriptions

void setup(p_effect: FoxEffect, p_target: Object) 🔗

Initializes the instance. This should only be called once immediately after creation.

void increase_stack(amount: int = 1) 🔗

Increases the stack count, strictly capped by FoxEffect.max_stacks.

If the stack successfully increases, this automatically triggers the effect’s FoxEffect.reapply() logic and emits stack_changed.

void decrease_stack(amount: int = 1) 🔗

Decreases the stack count.

If the stack reaches 0, it immediately emits request_destruction so the manager can purge it. Otherwise, it triggers FoxEffect.reapply() to scale down the math.

void process_time(delta: float) 🔗

Ticks down the internal timer.

Note: This does not automatically destroy the instance. The manager must check is_expired and handle cleanup.

void cleanup() 🔗

Safely delegates the reversal logic to the effect blueprint before this instance is destroyed.

void merge_duration(incoming_effect: FoxEffect) 🔗

Safely merges the duration of a new effect into this active instance based on the incoming effect’s FoxEffect.duration_mode.

Dictionary serialize() 🔗

Returns a dictionary containing the instance’s current state for saving.

void load_state(data: Dictionary) 🔗

Restores the private state from a saved dictionary. Must be called immediately after setup().

String _to_string() 🔗

Overrides the default print() behavior to show readable, human-friendly data instead of a raw memory ID (e.g., “poison x2 (4.5s)”).
