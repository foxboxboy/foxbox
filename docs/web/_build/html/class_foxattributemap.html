FoxAttributeMap

Inherits: FoxNode < Node

A recursive, hierarchical Blackboard node for safely managing dynamic entity data, stacked flags, and rules.

Description

Acts as a centralized data hub for an entity. It can store any arbitrary Variant data (such as int, String, or FoxStatPool resources), tracks temporary binary states via stacked string flags, and safely propagates FoxAttributeRules up and down a node hierarchy.

Property Descriptions

bool can_receive_rules = true 🔗

If true, this map will accept and apply rules propagated from a parent map.

bool can_send_rules = true 🔗

If true, this map will propagate its active rules down to any registered child maps.

Method Descriptions

void set_data(key: StringName, value: Variant) 🔗

Adds or updates a piece of data in the internal dictionary. Emits data_added if the key is new, or data_replaced if the key already exists.

Variant get_data(key: StringName, default_value: Variant = null) 🔗

Retrieves data associated with the given key. Returns default_value if the key does not exist.

bool has_data(key: StringName) 🔗

Returns true if the exact key exists in the data dictionary.

void erase_data(key: StringName) 🔗

Completely removes data associated with the given key and purges it from any associated groups. Emits data_removed.

void add_data_to_group(key: StringName, group: StringName) 🔗

Associates an existing data key with a specific group string for bulk querying.

void erase_data_from_group(key: StringName, group: StringName) 🔗

Removes a specific data key from a group.

void erase_data_from_all_groups(key: StringName) 🔗

Helper function that purges a key from all groups it currently belongs to.

Array get_data_in_group(group: StringName) 🔗

Returns an array of all actual data Variants currently associated with the target group.

void create_group(group: StringName) 🔗

Explicitly creates an empty group tracking array.

bool erase_group(group: StringName) 🔗

Completely destroys a group and disassociates all keys inside of it. Returns true if the group existed and was erased, or false if it did not exist.

bool has_group(group: StringName) 🔗

Returns true if the group exists.

void increment_flag(flag: StringName) 🔗

Adds one stack to a string-based flag. If this is the first stack applied, emits flag_added. Always emits flag_changed.

void decrement_flag(flag: StringName) 🔗

Removes one stack from a string-based flag. If the stack count reaches 0, the flag is erased entirely and emits flag_removed.

bool has_flag(flag: StringName) 🔗

Returns true if the flag exists with at least one stack.

int get_flag_stacks(flag: StringName) 🔗

Returns the exact number of times this flag has been stacked.

void erase_flag(flag: StringName) 🔗

Forcefully removes all stacks of a flag instantly.

void clear_all_flags() 🔗

Forcefully purges all active flags on the entity.

void add_rule(rule: FoxAttributeRule) 🔗

Applies a data-modifying FoxAttributeRule to the internal data and propagates it to children if can_send_rules is true.

void remove_rule(rule_id: StringName) 🔗

Removes a FoxAttributeRule by matching its FoxAttributeRule.rule_id. Reverses the rule’s mathematical effects on the local data and emits rule_removed.

Array[FoxAttributeRule] get_active_rules() 🔗

Returns the array of currently active and applied FoxAttributeRules.
