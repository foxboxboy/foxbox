Property Descriptions

Skeleton3D skeleton 🔗

The skeleton that the rigid accessories will attach to and the skinned accessories will deform to.

Dictionary _skinned_slots = {} 🔗

Tracks all instances of skinned accessories.

Array _rigid_accessories = [] 🔗

Tracks all instances of rigid accessories.

void _ready() 🔗

There is currently no description for this method. Please help us by contributing one!

void equip_rigid_accessory(accessory: Node3D, bone_name: String, reset_transform: bool = true) 🔗

Attaches a rigid item to any bone by its string name.

bool has_rigid_accessory_in_slot(bone_name: String) 🔗

Returns true if a rigid accessory could be found under a bone.

Array get_rigid_accessories_in_slot(bone_name: String) 🔗

Returns all rigid accessories assigned to a bone.

void empty_rigid_accessory_slot(bone_name: String) 🔗

Removes all rigid accessories assigned to a bone.

void clear_all_rigid_accessories() 🔗

Clears all rigid accessories from their slots. This effectively wipes the character back to having no rigid accessories.

void equip_skinned_accessory(accessory_root: Node3D, slot_name: String) 🔗

Equips a raw .gltf scene wrapper and automatically re-routes its internal meshes to use the skeleton assigned to this FoxCharacterAccessories,

Keeps track of the skinned accessory by the slot_name provided so that it can be found or removed later.

bool has_skinned_accessory_slot(slot_name: String) 🔗

Returns true if we have a value for that skinned slot.

Dictionary get_skinned_accessory_slots() 🔗

Returns dictionary showing all skinned slots. Each key is the name of the slot and the value is the Node its assigned to.

void empty_skinned_accessory_slot(slot_name: String) 🔗

Removes a skinned accessory by its slot name.

void clear_all_skinned_accessories() 🔗

Clears all skinned accessories from their slots. This effectively wipes the character back to having no skinned accessories.

void clear_all_accessories() 🔗

Clears all accessories from their slots. This effectively wipes the character back to having no accessories.
