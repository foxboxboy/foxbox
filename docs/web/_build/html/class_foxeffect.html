FoxEffect

Inherits: FoxResource < Resource

Inherited By: PoisonEffect

Base class for custom gameplay effects.

Description

FoxEffect is a Resource that defines the behavior, duration, and stacking rules for effects like spells, buffs, or environmental hazards. Because resources are shared by default, this class acts purely as a static data container.

When an effect is applied to a target, a separate FoxEffectInstance is spawned to track its active lifecycle (such as remaining time and current stacks).

To create a custom effect, extend this class and override _on_execute(), _on_remove(), and _on_reapply().

Enumerations

enum StackMode: 🔗

StackMode UNIQUE = 0

Prevents duplicate logic. Handles the timer based on duration_mode.

StackMode INTENSITY = 1

Increases the stack count up to max_stacks and calls _on_reapply().

StackMode MULTIPLE_INSTANCES = 2

Instantiates a completely separate timer. Ignores max_stacks and duration_mode.

enum DurationMode: 🔗

DurationMode ADD = 0

Adds the new duration to the existing time left.

DurationMode REFRESH = 1

Overwrites the current time left with the new duration (refreshes).

DurationMode KEEP_LONGEST = 2

Keeps whichever duration is longer.

Property Descriptions

StringName id 🔗

  • StringName @id_getter()

The unique identifier. If left blank, it falls back to the file name or memory ID.

StackMode stack_mode = 0 🔗

How the effect handles being applied to a target that already has it.

DurationMode duration_mode = 1 🔗

How the timer reacts when the effect stacks Used for StackMode.UNIQUE and StackMode.INTENSITY. While StackMode.MULTIPLE_INSTANCES ignores this.

int max_stacks = 0 🔗

The maximum allowed stacks if using StackMode.INTENSITY (0 = infinite).

float duration = -1.0 🔗

How long this effect will last in seconds.

Note: Set to -1.0 for permanent effects.

float tick_interval = 0.0 🔗

The frequency in seconds at which tick() triggers. Set to 0.0 to disable interval ticking.

Method Descriptions

void execute(target: Object) 🔗

Executes the initial application of this effect on the specified target.

This method ensures the target is a valid Object in memory before calling the virtual _on_execute() method. It is called automatically when a new effect instance is spawned.

void remove(target: Object) 🔗

Reverses the impact of this effect from the target.

This method ensures the target is a valid Object before calling the virtual _on_remove() method. It is called automatically when the effect’s duration expires or it is explicitly purged.

void reapply(target: Object, current_stack: int) 🔗

Updates the active effect on the target to match the new current_stack count.

This method ensures the target is a valid Object before calling the virtual _on_reapply() method. This is exclusively called when stack_mode is set to StackMode.INTENSITY and the FoxEffectInstance.stack count changes.

void tick(target: Object, current_stack: int) 🔗

Triggers the recurring _on_tick() logic.

This method ensures the target is a valid Object before executing.
