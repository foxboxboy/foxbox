FoxBoundedValue

Inherits: FoxResource < Resource

A resource that manages a float value within a defined minimum and maximum range.

Description

Emits signals for overflow and underflow, allowing for secondary mechanics such as overkill or overhealing.

Signals

value_changed(current: float, min: float, max: float) 🔗

Emitted when value, min_value, or max_value changes.

depleted(underflow: float) 🔗

Emitted when value falls below min_value. underflow contains the absolute difference.

saturated(overflow: float) 🔗

Emitted when value exceeds max_value. overflow contains the absolute difference.
