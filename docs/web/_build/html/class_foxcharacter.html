FoxCharacter

Inherits: FoxNode3D < Node3D

A high-level facade abstraction for a humanoid character that handles physics, animation, and interaction delegation.

Description

Designed to be controlled by an outside controller. This class acts as the “muscle” rather than the “brain”, blindly executing inputs and routing data between specialized components (State Machine, Pose Manager, Motors).

(WARNING this feature below is deprcated)

Note: If a FoxVisualOptimizer is assigned and the character is far away, visual processing and aim math are suspended to save performance.
