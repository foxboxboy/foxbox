FoxHitShapeCast3D

Inherits: ShapeCast3D

Delivers a Variant payload to all FoxHurtArea3D nodes it strikes.

Description

Acts as a “thick raycast” or swept-shape trigger. Perfect for thick lasers or high-speed melee sweeps that might tunnel through standard areas.

Properties

Variant

payload

Methods

void

fire()

Signals

hit_delivered(payload: Variant, target: FoxHurtArea3D) 🔗

Emitted when this shapecast successfully delivers its payload to a target.

Property Descriptions

Variant payload 🔗

The arbitrary data this shapecast will deliver upon intersection.

Method Descriptions

void fire() 🔗

Forces the shapecast to update immediately and attempts to deliver the payload.
