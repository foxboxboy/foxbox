FoxCharacterPoseManager
=======================

**Inherits:** :ref:`FoxNode<class_FoxNode>` **<** ``Node``

Component that manages the character's macro human configuration.

.. rst-class:: classref-introduction-group

Description
-----------

Acts as the definitive source of truth for the character's physical shape and visual stance. Resolves player intents against physical constraints, and allows specialized physics states to lock custom poses.
