GodotDoctorNodeValidationWarning
================================

**Inherits:** :ref:`GodotDoctorValidationWarning<class_GodotDoctorValidationWarning>` **<** ``MarginContainer``

A warning associated with a ``Node`` in the scene tree. Clicking the warning selects :ref:`origin_node<class_GodotDoctorNodeValidationWarning_property_origin_node>` in the scene tree. Used by :ref:`GodotDoctorDock<class_GodotDoctorDock>` to show validation warnings related to nodes.
