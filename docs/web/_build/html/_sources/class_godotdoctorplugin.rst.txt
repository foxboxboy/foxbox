.. _class_GodotDoctorPlugin_private_method__start_cli_start_fallback_timer:

.. rst-class:: classref-method

|void| **_start_cli_start_fallback_timer**\ (\ ) :ref:`🔗<class_GodotDoctorPlugin_private_method__start_cli_start_fallback_timer>`

Creates and starts the start fallback timer using :ref:`SceneTree.create_timer()<class_SceneTree_method_create_timer>`. When it times out, it posts the semaphore so the runner thread can proceed even if :ref:`_set_window_layout()<class_GodotDoctorPlugin_private_method__set_window_layout>` was never called.

.. rst-class:: classref-item-separator

----

.. _class_GodotDoctorPlugin_private_method__on_cli_start_fallback_timeout:

.. rst-class:: classref-method

|void| **_on_cli_start_fallback_timeout**\ (\ ) :ref:`🔗<class_GodotDoctorPlugin_private_method__on_cli_start_fallback_timeout>`

Called when the start fallback timer expires. Posts the semaphore so the runner thread is unblocked even without :ref:`_set_window_layout()<class_GodotDoctorPlugin_private_method__set_window_layout>` having been called.

|void| **_start_cli_quit_fallback_timer**\ (\ ) :ref:`🔗<class_GodotDoctorPlugin_private_method__start_cli_quit_fallback_timer>`

Creates and starts the quit fallback timer using :ref:`SceneTree.create_timer()<class_SceneTree_method_create_timer>`. When it times out, the process is force-quit with exit code 1.
