GodotDoctorReportPrinter
========================

**Inherits:** ``RefCounted``

Renders CLI validation results to stdout in rich-text format. Walks :ref:`GodotDoctorSummaryReport<class_GodotDoctorSummaryReport>` and its nested report objects, computing pass/fail status and summary statistics inline.
