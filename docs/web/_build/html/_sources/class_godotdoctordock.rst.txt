GodotDoctorDock
===============

**Inherits:** ``Control``

A dock for GodotDoctor that displays validation warnings. Warnings can be related to nodes or resources. Clicking on a warning will select the node in the scene tree or open the resource in the inspector. Used by :ref:`GodotDoctorEditorValidationReporter<class_GodotDoctorEditorValidationReporter>` to show validation warnings.
