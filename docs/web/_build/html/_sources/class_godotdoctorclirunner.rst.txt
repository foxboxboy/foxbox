GodotDoctorCLIRunner
====================

**Inherits:** :ref:`GodotDoctorRunner<class_GodotDoctorRunner>` **<** ``RefCounted``

A :ref:`GodotDoctorRunner<class_GodotDoctorRunner>` for headless / CLI mode. Iterates over all :ref:`GodotDoctorValidationSuite<class_GodotDoctorValidationSuite>` instances defined in :ref:`GodotDoctorSettings.validation_suites<class_GodotDoctorSettings_property_validation_suites>` and validates their scenes and resources.
