FoxCharacterState
=================

**Inherits:** :ref:`FoxState<class_FoxState>` **<** :ref:`FoxNode<class_FoxNode>` **<** ``Node``

**Inherited By:** :ref:`FoxCharacterAirState<class_FoxCharacterAirState>`, :ref:`FoxCharacterDashState<class_FoxCharacterDashState>`, :ref:`FoxCharacterGroundedState<class_FoxCharacterGroundedState>`

Base state for all character-driven states in the Foxbox framework.

.. rst-class:: classref-introduction-group

Description
-----------

**FoxCharacterState** extends the generic :ref:`FoxState<class_FoxState>` by introducing strictly typed variables for core character components. These variables are automatically injected by the parent :ref:`FoxCharacterStateMachine<class_FoxCharacterStateMachine>` during initialization.  Specific implementations should extend this class and use :ref:`@export<class_FoxCharacterState_annotation_@export>` to define their own specific motor needs.
