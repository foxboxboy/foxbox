FoxStatPool

Inherits: FoxResource < Resource

A resource that manages a dynamic value bounded by a modifiable maximum capacity.

Description

Combines a FoxModifiableStat for the maximum bound and a FoxBoundedValue for the current pool.

Note: Ensure Resource.resource_local_to_scene is enabled when assigning to multiple instances to prevent shared state.

Signals

updated(current: float, max_value: float) 🔗

Emitted when current or the maximum capacity changes.

depleted(underflow: float) 🔗

Emitted when current falls below 0.0. underflow contains the absolute value of the excess.

saturated(overflow: float) 🔗

Emitted when current exceeds the maximum capacity. overflow contains the excess amount.
