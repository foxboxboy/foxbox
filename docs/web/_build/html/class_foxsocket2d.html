Signals

attached(attachment: Node2D, socket: FoxSocket2D) 🔗

Emitted when this socket gains a new attachment.

detached(attachment: Node2D, socket: FoxSocket2D) 🔗

Emitted when the attachment leaves and is no longer a child.

attachment_changed(attachment: Node2D, socket: FoxSocket2D) 🔗

Emitted when the child order changes, useful for detecting deleted attachments.

Property Descriptions

Node2D marker 🔗

(Optional) The node that will be used for position, rotation, and scale. Leave blank to use this Marker2D’s transform.

bool snap_position = true 🔗

If true, the attachment’s global position snaps to the socket’s marker.

bool snap_rotation = true 🔗

If true, the attachment’s global rotation snaps to the socket’s marker.

bool snap_scale = false 🔗

If true, the attachment forcefully scales to match the socket marker’s global scale.

Node2D attachment = null 🔗

The child node currently plugged into this socket.

Method Descriptions

bool is_empty() 🔗

Returns true if there is no current attachment.

Node2D get_attachment() 🔗

Returns the current attachment node, or null if empty.

void attach(new_attachment: Node2D) 🔗

Reparents new_attachment to this socket and snaps its transform to marker.

Node2D detach() 🔗

Safely unplugs the attachment from the socket and returns it.

Note: This does not reparent the attachment anywhere else in the scene tree.
