FoxState

Inherits: FoxNode < Node

Inherited By: “addons/foxbox/state_machine/default_state.gd”, FoxCharacterState

Base class for all states within a FoxStateMachine.

Description

Custom states should override enter(), exit(), update(), and physics_update() as needed.

Properties

StringName

state_id

&""

Signals

transition_requested(old_state: FoxState, new_state_name: StringName) 🔗

Emitted when the state requests a transition to another state. old_state is a reference to the state requesting the transition. new_state_name is the string name of the target state.

Property Descriptions

StringName state_id = &"" 🔗

An optional custom identifier for this state. If left empty, the FoxStateMachine will use this node’s name instead.

Method Descriptions

void enter() |abstract| 🔗

Called by the FoxStateMachine when this state becomes the active state. Use this to initialize animations, reset variables, or apply initial forces.

void exit() |abstract| 🔗

Called by the FoxStateMachine immediately before transitioning away from this state. Use this to clean up variables or reset components before the next state takes over.

void update(_delta: float) |abstract| 🔗

Called every frame by the FoxStateMachine’s Node._process(). _delta is the time elapsed since the previous frame.

void physics_update(_delta: float) |abstract| 🔗

Called every physics frame by the FoxStateMachine’s Node._physics_process(). _delta is the time elapsed since the previous physics frame.
