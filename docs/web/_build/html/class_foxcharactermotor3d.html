FoxCharacterMotor3D

Inherits: FoxNode3D < Node3D

Inherited By: FoxAdvancedCharacterMotor3D

Moves itself based on an input direction and the strength of the input. Built in speed and jump_strength to control how fast the body moves and how high it can jump.

Property Descriptions

CharacterBody3D body 🔗

The body that will be acted upon. If unspecified, the node this is attached to will become the body.

float speed = 5.0 🔗

How fast the body will move.

float jump_strength = 9.5 🔗

How high the body will jump. Set to zero to disable jumping.

float gravity_multiplier = 2.5 🔗

How much the default gravity will apply. Makes the character feel more floaty (less than 1) or heavier (greater than 1).

Vector2 input_direction = Vector2(0, 0) 🔗

Direction the body will move when given input.

float input_strength = 1.0 🔗

How strong the input is, useful for joysticks.

bool active = true 🔗

  • void @active_setter(value: bool)

Whether or not this motor will process.
