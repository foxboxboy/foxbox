FoxInteractableArea3D

Inherits: Area3D

A physical volume that can be detected and interacted with.

Description

Designed to be extended or used in conjunction with signals. It accepts a generic Variant context during interaction, allowing the initiator to pass a Node, a Dictionary of parameters, or a custom context object.

Signals

interacted(context: Variant) 🔗

Emitted when interact() is called. The context contains data passed by the initiator.

focused(sensor: Node) 🔗

Emitted when a sensor (like a RayCast or Area3D) focuses this object.

unfocused(sensor: Node) 🔗

Emitted when a sensor unfocuses this object.

Method Descriptions

void interact(context: Variant = null) 🔗

Triggers the interaction logic. Pass any required data (like the player node or a context object) as the context.

void focus(sensor: Node) 🔗

Called automatically by an external sensor when this object is hovered or targeted.

void unfocus(sensor: Node) 🔗

Called automatically by an external sensor when this object is no longer targeted.

void _interact(_context: Variant) 🔗

Virtual method to be overridden in inherited scripts to define custom interaction logic.

void _focus(_sensor: Node) 🔗

Virtual method to be overridden in inherited scripts to define custom focus (hover) behavior.

void _unfocus(_sensor: Node) 🔗

Virtual method to be overridden in inherited scripts to define custom unfocus behavior.
