FoxBoundedValue
===============

**Inherits:** :ref:`FoxResource<class_FoxResource>` **<** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

A resource that manages a :ref:`float<class_float>` value within a defined minimum and maximum range.

.. rst-class:: classref-introduction-group

Description
-----------

Emits signals for overflow and underflow, allowing for secondary mechanics such as overkill or overhealing.
